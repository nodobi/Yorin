# 입력과 관련된 정책

## 레시피

| 항목             | 필수/선택 | 제한                 | 기타                             |
|------------------|-----------|----------------------|----------------------------------|
| 레시피 이름      | 필수      | 1 ~ 30자             | 중복 허용, 일부 특수문자 허용(1) |
| 레시피 조리 시간 | 선택      | 1000 미만 자연수     | 0으로 시작하는 수 가능           |
| 재료 목록        | 필수      | 1 ~ 30개             | 비어있는 카드 자동 제거          |
| 재료 명          | 필수      | 1 ~ 20자             | 줄바꿈 불가, 특수문자 불가       |
| 재료 수량        | 필수      | 10000 미만 자연수    | 0으로 시작하는 수 가능           |
| 재료 단위        | 필수      | 주어진 단위에서 선택 |                                  |
| 조리 순서 목록   | 필수      | 1 ~ 30개             | 순서는 자동으로 할당             |
| 조리 순서 내용   | 필수      | 1 ~ 300자            | 순서 변경 기능 필요              |
| 기록 일시        | 필수      | 현재부터 과거까지    | 기본값 현재 일시                 |
| 기록 별점        | 필수      | 1-5 정수             | 기본값 없음                      |
| 기록 한줄 평     | 선택      | 최대 30자            | 줄바꿈 불가                      |
| 기록 코멘트      | 선택      | 최대 1,000자         | 줄바꿈 허용                      |


(1). 허용하는 특수문자 `` !"#$%&'()*+,./:;<=>?@\[\\\]^_`{|}~\-‘’“”``
